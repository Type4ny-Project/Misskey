# T07 絵チャ

[みゅーさん](https://freeski.msnis.net/notes/arx2uv0drtfz01nc)、[白うささん](https://freeski.msnis.net/notes/arx2y5z7rtfz020i)、[ちょあよさん](https://freeski.msnis.net/notes/arx31ebirtfz027f)の提案をまとめた共同描画機能。2026年10月4日の回答に従い、Callsを土台に、公開ルーム・ChatRoomメンバー・Calls参加者の3つの参加範囲を扱う。

Callsルームの「アクティビティ」ボタンから一覧を開き、絵チャを選ぶ。絵チャは同じCallsルーム画面内に表示し、通話の操作と映像を維持する。一覧に戻る・アクティビティを閉じる操作では通話を終了しない。スマホ幅ではキャンバスを優先し、参加者のサイドバーを隠す。現在のアクティビティは絵チャのみで、将来の種類はこの一覧へ追加する。独立した絵チャページは設けない。ホストが最初に参加範囲を選ぶ。公開は公開の個人Calls、ChatRoomはChatRoomに紐づくCallsで選択できる。Calls参加者限定ではホストを含め、有効なCalls接続が必要。Calls自体の閲覧権限とChatの利用ポリシーも維持する。公開・ChatRoomでは音声接続は不要で、予約状態のCallsを開いて絵チャを開始できる。

キャンバスは1280×720、同時参加は16人。ペン、色、太さ、消しゴム、参加者一覧、短い文字チャットを提供する。ChatRoomでは既存のチャット履歴・投稿フォームを使い、それ以外では絵チャ内の直近50メッセージを保持する。描画イベントは文字チャット履歴へ保存しない。

現在の絵はRedisに保持する。途中参加、再読込、streaming再接続時はサーバーのキャンバスを取得する。Callsの既存ルームロックで、描画・消去・参加・終了と取得を直列化する。参加枠は30秒の更新と90秒の失効で管理し、画面を閉じた参加者が枠を占有し続けないようにする。音声なしで絵チャに参加するホストの更新はCallsの在席期限も更新し、利用中のルームが自動終了するのを防ぐ。キャンバス自体には参加者不在による有効期限を設けない。Redisの永続化・退避の設定は既存の運用に従う。

ホストは参加者を絵チャから退出させ、確認後に全消去または終了できる。退出させられた人は再参加・取得・描画できない。Callsから退出またはChatRoomから除外された人にも権限を再確認する。全消去でキャンバス識別子を更新し、送信待ちの古い線を拒否する。終了後は編集を再開できず、最後の絵を保存・投稿に添付できる。終了の確認に保存案内を表示する。

描画は最大64点の線分を約250ミリ秒ごとに同期し、現在の絵を構成する線分は10,000件まで保持する。上限時は画像保存とホストによる全消去を案内する。PNGは白い紙面で書き出し、既存のドライブアップロードと投稿フォームへの添付を使う。

レイヤー、無制限の履歴、終了後の編集再開、作品一覧、動画録画、筆圧対応は含めない。Cloudflareの音声・映像処理は変更しない。

完了条件は、2人での同期と途中参加・再読込の一致、参加範囲・退出に応じた取得と描画の制限、画像保存・添付、確認付き全消去の全員への反映。
